- Core
 核心运行时逻辑，如 GameManager、EventBus、InputManager 等
- Systems
 游戏系统模块，如 QuestSystem、CombatSystem、DialogueSystem
- GameplayHelpers
 数据转换、事件桥接、AI 生成内容绑定的辅助工具
- ScriptableObjects
 数据模板（SO），便于 AI 或策划生成任务、技能、敌人配置
说明：GamePlay 目录是唯一存放项目脚本的位置，区分核心逻辑、系统模块、辅助工具、数据模板。

---
2.2 ToBundle
- Prefabs
 人物/敌人/NPC/道具预制件，分子目录管理
- UI
 Panel/Popup 等 UI 预制件
- Sprites
 AI 生成或手动 Sprite 图集
- Json
 AI 生成的任务/对话/敌人配置 JSON
说明：AI 生成的资源存放在 ToBundle 下，打包 Addressables 时直接使用对应目录，保证动态加载与版本追溯。

---
2.3 Art
- Sprites：角色、敌人、道具
- Tiles：Tilemap 地图贴图
- Animations：Animation Clips / Animator Controller
- Effects：粒子和特效
- Materials：材质
说明：美术资源单独管理，AI 生成的 prefab / sprite 可引用，但不直接写入 Art。

---
2.4 Scenes
- Main.unity：主场景
- Test.unity：测试场景，用于 AI 生成内容落地验证

---
2.5 Content
- AI 游戏工作流内容管理
- Manual / Generated / Reviewed / Published 分层
- 与 Addressables + 元数据结合，实现 AI 内容流转与版本控制

---
2.6 Tools
- Review、Validators、Build
- 支撑基础设施层审核、校验、构建流程
