# 代码规范说明

---

## 准则

制定代码书写规范是为了让团队成员贡献代码时有参考标准，代码规范的制定准则主要侧重于：

- 是否易于阅读（Good for Read）
- 是否方便代码审核（Good for Code Review）
- 是否方便解决冲突（Good for Diff）

## 书写风格（Style）

我们的书写风格主要从 K&R 的编码风格派生而来，主旨是为了减少代码行数，降低阅读压力，减少可能产生 Diff 的情况。

---

### 大括号（brace）

- 规则：所有左大括号都和表达式在同一行，所有右大括号都另起一行。

```csharp
public class MyClass {
    void DoSomething() {
        if (someTest) {
            // ...
        }
    }
}
```

### 缩进（indentation）

- 规则：使用 4 空格（4 spaces）缩进，tab 键强制转成 4 空格间隔。

```csharp
public void DoSomething() {
    string name = "foobar";
}
```

### 空格（spacing）

- 规则：杜绝末端空格（trailing spaces），杜绝末端空行（trailing empty lines），杜绝多个空行（multiple empty lines）。

```csharp
private int foobar = 10;
private int id = 20;

public void DoSomething() {
    string name = "foobar";
    ChangeSpace();
}

private void ChangeSpace() { ... }
```

### 间隔（interval）

- 规则1：在数学符号两边加入一个空格作为间隔，在参数，for 表达式的间隔符后加入一个空格强化间隔效果。
- 规则2：方法，类之后需要接一个空格。

```csharp
private string name = "foobar";

obj.DoSomething(a, b, c);

if (a + 5 > method(blah() + 4)) { ... }

for (i = 0; i < 10; ++i) { ... }

public void DoSomething(int _a, int _b, int _c) { ... }
```

### 注释（comment）

- 规则1：在注释符号后面加一个空格开始你的注释。
- 规则2：在复杂的逻辑，或者 AI 训练的代码逻辑补充上详细的代码注释。

```csharp
// This is a comment
// 这是一行注释
/**
 * This is a comment with
 * multiple lines
 */
```

## 命名规范（Naming Conventions）

我们使用驼峰命名法（Pascal-Case）

---

### 文件名（filename）

- 规则1：使用 PascalCase 命名。
- 规则2：使用 “_” 作为补充文件说明。
```text
FooBar.cs
Foobar.cs
FooBar_Actions.cs
```

### 类（class）

- 规则1：使用 PascalCase 命名。
- 规则2：非必要情况不要继承 MonoBehaviour。

```csharp
public class FooBar { ... }
```

### 字段（field）

- 规则1：使用 camelCase 命名。
- 规则2：字段只能使用 private。
- 规则3：unity 关键字的命名使用 [SerializeField] 进行序列化。
- 规则4：const、static、readonly 需要全部用大写字母，单词间用 _ 隔开。

```csharp
public class FooBar {
    private const int CONST_FIELD = 1;
    private readonly int READONLY_FIELD;
    private int fooBar;
    [SerializeField] private Transform fooBarTransform;
}
```

### 属性（property）

- 规则：使用 PascalCase 命名。

```csharp
private string name;
public string Name {
    get { return name; }
    set { name = value; }
}
```

### 局部变量（variable）

- 规则：使用 camelCase 命名。
- 规则：支持 var 和其他声明混用。

```csharp
public void DoSomething() {
    float speed = 20.0f;
    bool useWeapon = false;
    var role = new Role();
    ...
}
```

### 参数（parameter）

- 规则1：使用 camelCase 命名。
- 规则2：当参数命名和成员变量命名一致时，使用 this 索引成员变量。
- 规则3：当参数命名和 static 成员变量命名一致时，使用 camelCase_ 命名（加下划线后缀）。

```csharp
public void DoSomething(Vector3 location) { ... }

public class MyClass {
    float speed = 0.0f;
    static float speedScale = 1.0f;

    public void SetSpeed(float speed) {
        this.speed = speed;
    }

    public static void SetSpeedScale(float speedScale_) {
        speedScale = speedScale_;
    }
}
```

### 委托（delegate）

- 规则1：使用 PascalCase 命名并在名字末端加入 EventHandler 或者 Callback。
- 规则2：C# 的 Action；声明的委托，使用赋值方式，不要使用 +=。

```csharp
private delegate void ClickEventHandler();
private delegate void RenderCallback();
private RenderCallback readerCallback;
private Action action;

public class MyClass {
    public void AddEvent(RenderCallback readerCallback, Action action) {
        this.readerCallback = readerCallback;
        this.action = action;
    }
}
```

### 布尔变量（boolean variables）

- 规则：使用 is、has 或者 can 作为前缀命名变量名。

```csharp
public class MyClass {
    private bool isPerson = true;
    private bool hasAge = true;
    private bool canDance = true;
}
```

## 语句（Statements）

我们要求所有表达式都需要写完整格式，不能写简化版本。

---

### if 语句

- 规则1：书写规则为 if (…) {，若有 else 表达式，则 else 紧跟在 if 结束后。
- 规则2：所有表达式的内容只有一句话也不能取消 { }。

```csharp
if (i > 0) {
    return false;
}

if (i > 1) {
    return false;
}

if (i > 2) {
    thing1();
} else if (i < -2) {
    thing2();
} else {
    thing3();
}
```

### 循环语句

- 规则：书写规则为 for (a…; b…; c…) {，while (…) {，do { … } while ();。

```csharp
for (int i = 0; i < 10; ++i) {
    thing1();
}

while (true) {
    thing1();
}
```

### switch 语句

- 规则：书写规则为 switch (…) {

```csharp
switch (variable) {
    case 1: thing1(); break;
    case 2: thing2(); break;
    case 3: thing3(); break;
}

switch (variable) {
    case 1:
        thing1();
        break;
    case 2:
        thing2();
        break;
    case 3:
        thing3();
        break;
}
```

## 网络传输规范（Netwrok Transmission）

依据项目现有框架结构进行限制，在框架进行改变时，该规范会有相应调整。

---

### [Command] 方法

- 规则1：所有 command 方法需要放在对应的 NetWorkBehaviour 类里面。
- 规则2：本地调用不能直接访问 NetWorkBehaviour 中的 Command 方法，需要从对应的 Client 里进行调用。
- 规则3：禁止在 Server 的逻辑里调用 command 方法。
- 规则4：禁止在 Update 中频繁调用 command 方法。

```csharp
public class MyClass {

    public void SetSpeed(float speed) {
        MyClassNetClient.SetSpeed(speed);
    }
}

public class MyClassNetClient {

    public void SetSpeed(float speed) {
        MyClassNet.CmdSetSpeed(speed);
    }
}

public class MyClassNet : NetWorkBehaviour  {

    [Command]
    public void CmdSetSpeed(float speed) {
        MyClassServer.SetSpeed(speed);
    }
}

public class MyClassServer {

    public void SetSpeed(float speed) {
        // ...
    }
}
```

## 代码设计（Code Design）

---

### 篇幅

- 规则1：类型，单个类（同一个类型文件）代码行数不推荐超过 500 行，如遇需求增加或内容扩展，不应该超过 1000 行。
- 规则2：方法，单个方法体代码推荐维持在 50 行以内。
- 规则3：例外，篇幅并不是一个强制性要求，如果代码逻辑非常扁平，比如某些工具类或某些完全并行的逻辑，可不遵守上述原则。

### 补充规范

- 废弃的代码直接删除掉。
- Invoke 禁止使用，使用 ClockUtil 代替。

```csharp
public class MyClass {

    public void SetSpeed(float speed) {
        // 禁止
        // Invoke("OnAddSpeed", 3f);

        // 推荐
        ClockUtil.Instance.AlarmAfter(3f, OnAddSpeed);
    }

    public void OnAddSpeed() {
        // ...
    }
}
```

## 排版（Layout）

---

有以下几点注意事项：

- 规则1：静态字段的声明放在最上方。
- 规则2：成员变量和属性集中放置于类型文件头部，有强逻辑关系或者成对使用的字段和属性中间不空行，其他字段或属性中间空一行。
- 规则3：方法代码块和方法代码块之间空一行，不能不空行，也不推荐空多行。
- 规则4：方法代码块中，同一逻辑块的代码紧密相连，非同一逻辑块中间空一行，本地变量的声明和使用要紧密相连。
- 规则5：函数生命周期成块出现。

```csharp
public class MyClass {
    private const int CONST_FIELD = 1;
    private readonly int READONLY_FIELD;

    private int nameA;
    private string infoA;

    private int nameB;
    private string infoB;

    public void Init() {

    }

    public void Clear() {

    }

    public void SetAInfo() {
        this.readerCallback = readerCallback;
        this.action = action;
    }
}
```
