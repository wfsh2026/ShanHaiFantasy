项目名称：ShanHaiFantasy
目标：生成游戏项目中任意功能模块的通用程序文档，用于开发团队阅读、维护以及 AI 记忆继承。

说明：
该文档由 Codex 根据已有功能模块代码生成，适用于 Addressables 资源加载、系统模块、UI 管理、AI 生成内容等功能。

目录结构：
请根据具体模块对应项目目录生成，如 Assets/Scripts/GamePlay/ModuleName/

文档要求：
1. 文档类型：中文程序文档，面向策划和开发人员
2. 必须包含以下内容：
   - 类图：展示模块内主要类及其关系
   - 流程图：功能执行、数据流或资源加载、事件触发等流程
   - 核心接口说明：公共方法的参数、返回值、功能说明、使用限制
   - 调用示例：典型调用场景示例代码
   - 异常处理说明：异常类型、触发条件及处理方法
   - 与 AI 内容或其他模块集成说明：Key/ID 管理、版本管理、依赖关系说明
   - 目录与资源映射说明：模块对应的资源路径和分组策略
   - 注意事项与最佳实践
3. 文档格式：
   - 文字描述 + 图示（类图、流程图）
   - 表格或条目形式说明接口和使用方法
4. 补充内容建议（Codex 可自由生成）：
   - 内存管理和缓存策略说明
   - 线程安全说明（异步或事件驱动功能注意事项）
   - 扩展方案建议（如何新增功能、资源类型或系统模块）
5. 输出形式：
   - Markdown 或 Word 文档格式
   - 内容完整，便于直接阅读和归档
6. 示例输出段落结构（Codex 可参考）：
   1) 文档概述
   2) 类图
   3) 核心接口表格
   4) 功能/资源流程图
   5) 调用示例
   6) 异常处理与注意事项
   7) AI或跨模块集成说明
   8) 扩展与维护建议
