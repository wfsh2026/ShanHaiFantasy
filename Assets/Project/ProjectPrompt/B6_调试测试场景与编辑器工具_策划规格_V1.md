# B6_调试测试场景与编辑器工具_策划规格_V1

## 1. 文档信息

- 文档名称：B6_调试测试场景与编辑器工具_策划规格_V1
- 文档路径：`Assets/Project/ProjectPrompt/B6_调试测试场景与编辑器工具_策划规格_V1.md`
- 当前状态：基础原型已落地，进入返修对齐

## 2. 目标

- 为 B 组后续持续迭代提供最小可用的调试面板与测试场景入口。

## 3. 范围

- QuickSetupPanel
- BattleTestScene 完善
- CultivationTestScene
- 最小调试动作：
  - 强制阶段
  - 强制阵眼
  - 增减气运
  - 一键推进到养成/布阵验证点

## 4. 规则

- 调试工具只服务测试场景和开发验证，不进入正式玩家逻辑入口。
- 调试入口优先复用 Battle 主链，不新起平行 BattleMode。

## 5. 完成标准

- 在测试场景中能快速进入养成和布阵验证状态。
- 调试按钮不会破坏 A1-A7 现有可运行链路。

## 6. 当前返修判断

- 当前实现已经有测试场景和调试入口，但调试表达与验证信息仍混入玩家主路径，破坏正式体验。
- 调试工具仍应保留，但必须只服务测试场景和开发验证，而不是继续占据正式玩法界面的主体心智。
- 本案后续返修并入 `C3_正式养成界面与调试隔离_策划规格_V1.md`。
