## 5. 功能目标

- 把当前玩家主路径里的验证表达与调试入口剥离出去
- 让 `BattleA2Panel` 收束为正式玩家界面
- 保留测试场景里的调试能力，但不自动注入到正式玩家路径
- 不追求：
  - 完整美术重做
  - 新起一套完全独立的 UI 系统

## 6. 架构归属

- 本需求涉及层级：
  - `Controller`
  - `Feature`
  - `Test`
- 归属原因：
  - 主要修改 UI 展示层和测试场景验证入口
  - 不改 `Base` 和 battle 权威逻辑
- 是否影响现有主链：
  - 会影响玩家看到的 Battle 主界面
  - 不改变 `BattleMode` 主状态流转

## 8. 模块拆分

- 模块名称：正式 Battle 主界面收口
  - 模块类型：UI / Controller
  - 模块职责：把 `BattleA2Panel` 收束为正式玩家界面
  - 关系：只消费 `BattleModeData`
  - 是否新增：否，扩展现有面板
- 模块名称：测试调试入口隔离
  - 模块类型：Test / UI

  - 关系：依赖 `BattleQuickSetupPanel`、`QuickSetupPanel`、`BattleA2SceneVerifier`
  - 是否新增：否
- 模块名称：场景自动打开策略修正
  - 模块类型：Client Feature / Test
  - 模块职责：区分正常玩家路径和测试场景的自动打开逻辑
  - 关系：依赖 `ClientBattleModeManager` 与场景判定
  - 是否新增：否

## 9. 数据流与状态流

- `Config`
  - 本任务不新增配置资产
- `Data`
  - 沿用现有 `BattleModeData`
- `Logic`
  - 不新增战斗权威逻辑
  - 只调整“何时打开何种面板、何时注入调试入口”
- `UI`
  - 正式玩家路径只显示玩法信息
  - 测试场景才显示调试和验证入口

## 10. Client / Server 责任分配

- 客户端负责：
  - 正式界面展示
  - 调试入口与测试路径隔离
  - 场景中的自动打开策略
- 服务端负责：
  - 无新增职责
- 不需要新增同步字段
- 不能越界的点：
  - 不把调试入口做成服务端权威功能的一部分
  - 不因为调试需求污染正式玩家路径

## 11. 关键流程

1. 正常玩家进入 battle 流程
2. `ClientBattleModeManager` 仅打开正式主界面
3. 正式主界面只显示玩家当前阶段需要的信息
4. 测试场景进入时，才允许额外打开验证器或调试面板
5. `BattleA2SceneVerifier` 不再把调试入口自动注入正常玩家路径

### 测试路径流程

1. 进入 `BattleTestScene` 或 `CultivationTestScene`
2. 主动或按测试场景策略打开调试入口
3. 使用调试入口推进阶段、验证表现

## 13. 进入条件、完成出口与回退策略

- 进入实现前条件：
  - 当前 `BattleA2Panel`、`BattleQuickSetupPanel`、`QuickSetupPanel` 已存在
  - 测试场景与正式玩家路径的差异已在文档中明确
- 最小完成出口：
  - 正常玩家路径不再自动显示验证器和调试入口
  - 测试场景仍保留强制推进能力
  - 正式主界面只保留玩法语义内容
- 回退策略：
  - 若一次性重构 UI 风险过大，首版优先先做“隐藏验证语义 + 隔离调试入口”，不一次性重做全部布局

## 14. 测试与验证方案

- 测试入口：
  - `RoomEntryScene -> BattleTestScene`
  - `CultivationTestScene`
- 验证步骤：
  1. 从正常玩家路径进入 battle
  2. 确认默认不出现验证器和调试按钮
  3. 进入测试场景
  4. 确认可以主动打开调试入口并继续验证
  5. 确认调试入口不会破坏 A1-A7 主链
- 预期结果：
  - 玩家路径干净
  - 测试路径仍高效

## 15. 风险与待确认项

- 风险点：当前 `BattleA2Panel` 已同时承担多个阶段与验证职责
  - 影响：C3 实现时容易和 C1/C2 的信息补充互相打架
  - 建议：先明确“正式玩家必须看到什么”，再把验证内容退回测试入口
- 风险点：`BattleQuickSetupPanel` 与 `QuickSetupPanel` 存在双入口
  - 影响：后续很容易继续混用
  - 建议：本任务中明确保留哪一个作为测试主入口
- 待确认项：
  - 正式玩家路径是否保留极简帮助入口
  - 测试入口最终保留面板版还是 `OnGUI` 版为主
