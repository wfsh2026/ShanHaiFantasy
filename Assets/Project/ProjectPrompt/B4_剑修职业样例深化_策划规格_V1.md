# B4_剑修职业样例深化_策划规格_V1

## 1. 文档信息

- 文档名称：B4_剑修职业样例深化_策划规格_V1
- 文档路径：`Assets/Project/ProjectPrompt/B4_剑修职业样例深化_策划规格_V1.md`
- 当前状态：基础原型已落地，进入返修对齐

## 2. 目标

- 让剑修成为首个完整职业样板，体现开局、养成、战斗和站位差异。

## 3. 范围

- 剑意资源
- 四个剑修模板：连斩、御剑、绝杀、破阵
- 开局三选一中的模板差异
- 养成路线偏好
- 战斗计算偏好
- 站位偏好与阵眼联动

## 4. 规则

- 四个模板必须做到选时有区别、养成时有区别、战斗时有区别。
- 剑意只作为首版职业专属资源，不扩展到所有职业。

## 5. 完成标准

- 主角候选中稳定出现剑修模板样例。
- 养成选项和战斗得分对不同剑修模板有不同权重反馈。
- UI 能展示剑修模板名与剑意状态。

## 6. 当前返修判断

- 当前实现已经有多个剑修模板和剑意字段，但差异更多体现在内部权重，玩家实感层面的模板区别仍不够强。
- 当前剑修模板在开局、养成、战斗三个阶段都缺少足够鲜明的可感知反馈，容易让玩家感觉“只是几套名字不同的数值模板”。
- 本案后续返修并入 `C5_内容池扩容与职业差异强化_策划规格_V1.md`，优先把剑修样例做成首个真正有辨识度的职业模板。
