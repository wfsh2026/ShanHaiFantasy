## 2. 核心玩法一句话

- 宗门大比是一款“多人房间进入单局、单主角修仙构筑、自动战斗、多轮淘汰决出胜者”的修仙题材原型游戏。

## 3. 开发计划一句话

- 当前开发已完成 A 组最小循环和 B 组内容原型，但玩家体验尚未达到策划目标，下一步按 C 组返修 TASK 收口战斗反馈、养成生效、正式界面、AI 决策与内容差异。
