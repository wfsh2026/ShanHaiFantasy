# C2：养成承载真实生效

## 1. Task 基本信息

- Task ID：C2
- Task 名称：养成承载真实生效
- 所属总策划案：`宗门大比总策划案`
- 优先级：P0
- 前置依赖：A6、A7、B2、B3

## 2. 功能目标

- 解决当前养成更像“加数值包”，而不是“改变下一轮构筑状态”的问题。
- 让主选项、次结果和承载落位真正影响下一轮战斗结果与说明。
- 让五线承载从展示字段升级为玩家能理解的战斗准备状态。

## 3. 玩家体验目标

- 玩家选完养成后，能明确知道这次选择落到了哪条线、哪个承载位、下一轮会偏向什么。
- 玩家在下一轮战斗或结算时，能感到上一轮承载变化确实产生了影响。
- 玩家不会再觉得“无论选什么都只是加几个数字”。

## 4. 核心规则

### 4.1 养成落点规则
- 每次养成选择必须明确告诉玩家主结果落到哪个承载位、次结果落到哪个承载位。
- 若新结果覆盖旧结果，界面必须明确提示“被替换”的旧承载内容。
- 不允许把承载变化只留在内部字段，不在玩家侧表达。

### 4.2 五线反馈规则
- 物、法、财、伴、地五线都必须在战斗结果或战斗原因中找到可感知反馈。
- 至少要做到：不同线的成长不只影响同一个总分入口，而是影响不同的战斗原因说明或收益方向。
- 地线与站位、阵眼收益必须形成更强联动。

### 4.3 结果承接规则
- 养成完成后，本轮选择结果必须作为“下一轮准备状态”稳定可见。
- 下一轮战斗若受上一轮承载影响，结果反馈中要能指出对应来源。

### 4.4 异常规则
- 若某条线当前没有有效承载内容，界面要明确显示“空位/未成型”，而不是与已成型状态看起来一样。
- 若玩家重复命中同一承载位，必须有明确替换或强化说明。

## 5. UI 需求

- 主选项与次结果落点说明区
- 五线承载状态区
- 下一轮准备状态摘要区

## 6. 流程顺序

1. 玩家进入 Cultivation 阶段。
2. 玩家查看 4 个主选项及其承载落点。
3. 玩家确认选择后，当前界面立即反馈本轮承载变化。
4. 玩家进入 FormationConfirm 与下一轮 Battle。
5. 下一轮结果中能回溯上一轮承载变化带来的影响。

## 7. 验收标准

- 玩家能说出本轮养成选到了哪条线、落到哪个承载位、预计下一轮会带来什么偏向。
- 至少三类不同承载变化能在后续战斗结果中被明显感知。
- 五线里任意一条为空时，界面状态与已承载状态有清晰区别。

## 8. 不做范围

- 不做完整职业树或局外养成。
- 不做多层级稀有度系统。

## 9. 待确认项

- 首版要优先强化哪几类“承载变化 -> 战斗反馈”映射。
- 首版是否需要给出“被覆盖承载”的专门回看入口。
