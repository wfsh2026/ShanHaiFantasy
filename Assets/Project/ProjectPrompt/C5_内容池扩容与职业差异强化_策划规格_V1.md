# C5：内容池扩容与职业差异强化

## 1. Task 基本信息

- Task ID：C5
- Task 名称：内容池扩容与职业差异强化
- 所属总策划案：`宗门大比总策划案`
- 优先级：P1
- 前置依赖：B2、B3、B4

## 2. 功能目标

- 解决当前主角模板和养成选项重复感较强的问题。
- 拉开不同主角模板、养成方向和剑修样例之间的多局差异。
- 让玩家连续开多局时仍能感到新鲜方向和构筑取舍。

## 3. 玩家体验目标

- 玩家在多局中能遇到更多不同的起手模板与成长路线。
- 不同剑修模板在开局、养成和战斗里都能形成清晰区别。
- 玩家不会很快觉得“每局只是同样内容重排”。

## 4. 核心规则

### 4.1 主角模板规则
- 首版主角模板池必须扩到足以支撑连续多局的基础差异。
- 模板差异不能只体现在名字和数值，要体现在偏好、站位和成长方向。

### 4.2 养成内容规则
- 主选项池与次结果池都要扩充可用条目。
- 新条目要服务不同构筑方向，而不是只做同质化替换。

### 4.3 剑修样例规则
- 剑修必须成为首个“玩家能明显感到不同模板差异”的职业样例。
- 不同剑修模板在开局、养成和战斗三个阶段都要有可感知区别。

## 5. 流程顺序

1. 玩家开局遇到不同主角模板。
2. 中期看到不同养成方向与承载落点。
3. 战斗与结果反馈出不同职业和构筑差异。

## 6. 验收标准

- 连续进行多局时，玩家不会高频遇到完全同质的模板与选项组合。
- 至少数个剑修模板能被玩家稳定区分并说出其风格差别。
- 新增内容不会破坏当前 A-C 主链流程。

## 7. 不做范围

- 不做多职业大规模铺开。
- 不做局外收集与长线图鉴系统。

## 8. 待确认项

- 首版扩容优先补主角模板还是先补主选项池。
- 剑修之后第二个优先职业样例的方向是什么。
