# B3_五大模块深化_策划规格_V1

## 1. 文档信息

- 文档名称：B3_五大模块深化_策划规格_V1
- 文档路径：`Assets/Project/ProjectPrompt/B3_五大模块深化_策划规格_V1.md`
- 当前状态：基础原型已落地，进入返修对齐

## 2. 目标

- 把 A6 的五线样本升级为各自有明确承载位和玩法方向的首版原型。

## 3. 范围

- 物：兵器、法宝、护具、炼体
- 法：主功法、心法、神通
- 财：洞府、宝阁、委托
- 伴：宠物/器灵、辅助方向
- 地：阵法、阵眼、前中后位

## 4. 规则

- 五条线都服务于单主角成长，不独立脱离主角体系。
- 同槽位新结果覆盖旧结果。
- 地线必须能影响回合战斗分数与站位收益。

## 5. 完成标准

- 五条线在主角承载面板中都有明确显示位置。
- 每回合养成选项能实际改变至少一个承载位。
- 承载变化能反馈到后续战斗结果。

## 6. 当前返修判断

- 当前实现已经具备五线承载槽位和基础写入，但更多停留在“显示位 + 加法收益”，还不足以支撑明确的构筑反馈。
- 当前承载变化对后续战斗的影响仍偏弱，玩家更容易看到数字变化，而不是看到某条线怎样改变了战斗方式或结果原因。
- 本案后续返修并入 `C2_养成承载真实生效_策划规格_V1.md`，重点补足承载变化到战斗反馈的体验闭环。
