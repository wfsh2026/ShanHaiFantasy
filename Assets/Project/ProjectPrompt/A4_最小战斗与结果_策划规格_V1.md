# A4_最小战斗与结果_策划规格_V1

## 1. 文档信息

- 文档名称：A4_最小战斗与结果_策划规格_V1
- 文档路径：`Assets/Project/ProjectPrompt/A4_最小战斗与结果_策划规格_V1.md`
- 文档版本：V1
- 文档状态：当前执行版
- 负责人：策划
- 更新时间：2026-03-30

## 2. 任务目标

- 让 `Battle` 阶段不再只是时间推进，而是为每名仍在局中的参与者产出一份可用于后续扣气运的明确战斗结果。

## 3. 当前版本范围

- 单主角自动战斗
- 存活参与者的 1v1 配对
- 支持 `胜 / 负 / 平 / 轮空`
- `BattleResult` 阶段展示本回合结果
- 战斗结果进入后续 A5 扣气运逻辑

## 4. 当前版本规则

- 每回合 `Battle` 只做最小权威结算，不做正式战斗演出。
- 首版配对规则允许按服务端确定的固定顺序配对。
- 若本回合存活人数为奇数，最后 1 名参与者记为 `轮空`。
- 战斗结果必须由服务端产出并同步给所有客户端。
- `BattleResult` 阶段必须能看到本回合的对手、得分和结果类型。

## 5. 输入与输出

- 输入：
  - A2 产出的本局唯一主角
  - A3 已建立的回合阶段
  - 当前回合前的主角成长结果
- 输出：
  - 本回合对手信息
  - 本回合战斗得分
  - 本回合结果类型
  - 可供 A5 使用的结算依据

## 6. 完成标志

- `Battle` 阶段可以稳定产出结果
- `BattleResult` 阶段能承接并展示结果
- 结果至少区分胜、负、平、轮空
- 结果由服务端权威同步，不由客户端推断

## 7. 当前明确不做

- 不做真实技能释放与战斗演出
- 不做正式战斗场内单位生成
- 不做复杂匹配与站位策略
